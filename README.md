# AI-Powered Roadmap Generator  

## Overview  
**Roadmap Generator** harnesses the power of the **COHERE API** to provide **personalized learning paths** based on your chosen skill and specific learning requirements. Our AI meticulously constructs a **tailored roadmap** to guide you through your learning journey efficiently.  

With **Roadmap Generator**, you can:  
✅ **Generate AI-driven learning roadmaps**  
✅ **Save roadmaps as PDFs** for easy access and future reference  
✅ **Take quick notes** and export them as PDFs  
✅ **Track progress visually** to stay motivated  
✅ **Enjoy a responsive design** for seamless use across devices  

## Features  
- **AI-Integrated Roadmap Creation**: Get a **customized learning path** for any skill of your choice.  
- **PDF Export for Roadmaps & Notes**: Save your learning plan and notes for offline access.  
- **Quick Notes Sidebar**: Jot down **important insights** and **save them instantly**.  
- **Progress Tracking**: Stay on top of your learning goals with a **visual progress tracker**.  
- **Seamless User Experience**: Fully **responsive design**, ensuring smooth functionality across all devices.  

## Technologies Used  
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **AI Integration:** COHERE API  
- **Database:** MongoDB (for storing user data and roadmaps)  
- **PDF Generation:** jsPDF  

## Installation  

### Prerequisites  
- **Node.js** and **npm** installed on your system  

### Steps  
1. **Clone the Repository:**  
   ```bash
   git clone https://github.com/garimabhayanaa/RoadMap-Generator
   cd Roadmap-Generator
2. **Install Dependencies:**
   ```bash
    npm install
3. **Start the Backend Server:**
   ```bash
    npm run server
4. **Start the Frontend:**
   ```bash
    npm start
5. **Access the Application:**
   Open your browser and visit http://localhost:3000 to start generating learning roadmaps!

## Usage
1. Enter Your Desired Skill & Learning Requirements
2. Generate an AI-Powered Roadmap
3. Save Roadmaps & Notes as PDFs for Future Reference
4. Track Your Progress with Visual Indicators
